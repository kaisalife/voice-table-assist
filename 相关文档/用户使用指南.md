# VoiceTableAssist 用户使用指南——语音输入规则与示例

> 依据现有实现整理，供现场操作人员与测试人员使用。

## 一、概述

一句话语音即可填入一个或多个表格单元格。输入规则：先说**行名**（或**列号**），再说**位置**与**值**。三种典型用法：逐行填入、逐列填入、单值修改。

---

## 二、输入规则

| 规则 | 说明 | 示例 |
|---|---|---|
| **行名开头** | 每次录入**会话**的第一句必须说明行名（如「水位」）；同一会话内后续语句可省略行名，沿用前文主体 | 首句 `水位，一号是五十点零`；后句 `二号是四十九点八`（自动归入水位行） |
| **列式填入** | 支持逐列填入：先说列号（如「第一列」），再说行标签与值 | `第一列，硬度填十，圆度是五十` |
| **助词灵活** | 行名后可接「测量值是 / 填 / 改为 / 为」，或不加助词直接接值 | 见下方助词示例 |
| **跳位填入** | 无需一次说完一整行，可跳着输入，但每次至少填入一个位置 | `硬度，一号是五十，三号是二十` |
| **单值修改** | 直接说「行名 + 位置 + 值」即可修改单个格子 | `硬度，测量值二是十` |
| **负值** | 直接说「负」，如「负九十五」→ -95（负压/真空场景） | `真空，一号是负九十五` |
| **提交时机** | 说完停顿约 **2 秒**自动提交填表；或点「结束录音」立即提交。同一会话的累计文本保留，后续语句可省略行名 | 说完 `水位，一号是五十` 停 2 秒 → 表格自动填充 |

**助词示例**（均可识别）：

1. `测量值一是五十点零`
2. `测量值二填四十九点九九`
3. `测量值三改为五十一点五`
4. `测量值四为六十点七五`
5. `测量值五八十`（不加助词直接接值）

**省略规则**：

| 项 | 可否省略 |
|---|---|
| 行名 | 首句不可省略；**同一会话内**前文已含行名时可省略（累计上下文延续，如「二号是六十」沿用前文「水位」） |
| 「巡检登记」 | 可省略，直接从行名开始 |
| 「测量值几」 | 可换成「几号」以减少字数 |
| 「是」 | 可省略，直接说值（视习惯而定） |

**位置说法**：行说「序号一 / 第一行 / 外径」、列说「二号 / 第二个 / 测量值几」均可，指同一格。

## 三、标准样例

**样例一**

> 巡检登记，硬度，测量值一是五十点零，测量值二是四十九点九九，测量值三是五十一点五，测量值四是六十点七五，测量值五是六十六点七五，测量值六，四十八点七七

**样例二**

> 巡检登记，硬度，一号是五十点零，二号是四十九点九九，三号是五十一点五，四号是六十点七五，五号是六十六点七五，六号是四十八点七七

## 四、测试用例

### 1. 逐行填入（「X号」格式）

**输入**

> 巡检登记，硬度，一号是五十点零，二号是四十九点九九，三号是五十一点五，四号是六十点七五，五号是六十六点七五，六号是四十八点七七

**输出**

```json
[
  { "row": 4, "column": 1, "values": 50 },
  { "row": 4, "column": 2, "values": 49.99 },
  { "row": 4, "column": 3, "values": 51.5 },
  { "row": 4, "column": 4, "values": 60.75 },
  { "row": 4, "column": 5, "values": 66.75 },
  { "row": 4, "column": 6, "values": 48.77 }
]
```

### 2. 逐行填入（「测量值X」格式）

**输入**

> 巡检登记，硬度，测量值一是五十点零，测量值二是四十九点九九，测量值三是五十一点五，测量值四是六十点七五，测量值五是六十六点七五，测量值六，四十八点七七

**输出**

```json
[
  { "row": 4, "column": 1, "values": 50 },
  { "row": 4, "column": 2, "values": 49.99 },
  { "row": 4, "column": 3, "values": 51.5 },
  { "row": 4, "column": 4, "values": 60.75 },
  { "row": 4, "column": 5, "values": 66.75 },
  { "row": 4, "column": 6, "values": 48.77 }
]
```

### 3. 逐列填入

**输入**

> 第一列，硬度填十，圆度是五十

**输出**

```json
[
  { "row": 4, "column": 1, "values": 10 },
  { "row": 6, "column": 1, "values": 50 }
]
```

## 末、存疑点

1. 「是」可省略一项为「视习惯而定」，是否存在明确不建议省略的场景（如连续数值导致歧义）？
2. 单值修改与新增填入在系统内部是否有区分（如覆盖确认提示），还是统一为直接覆盖？
3. 列式填入时行标签的顺序（先列后行）是否唯一支持的语序，行在列后的说法是否支持？
4. 跳位填入时未填的格子是否保留原值不动？
5. 本指南的示例基于 6×6 生产模板表，换其他表时规则是否完全一致？
